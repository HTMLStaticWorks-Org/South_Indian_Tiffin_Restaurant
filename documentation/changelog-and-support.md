# Changelog & Support Information

## Changelog

### Version 1.0.0 — Initial Release (November 2026)
- Delivered all 7 bespoke pages (`index.html`, `home-2.html`, `menu.html`, `our-story.html`, `contact.html`, `404.html`, `coming-soon.html`) with distinct heroes, zero repeated sections, and zero repeated images.
- Built custom South Indian culinary colour system (`--leaf`, `--turmeric`, `--kumkum`, `--coconut`, `--filter-coffee`, `--brass`) with WCAG 2.1 AA contrast across Coconut Cream Light Mode and Filter-Coffee Dark Mode.
- Added full Right-to-Left (`rtl.css` + persisted toggle) support across all pages.
- Engineered vanilla ES6+ plugins: 3D Tilt + Glare (`tilt.js`), Live Serving Status + Analog Brass Clock + Scroll Counters (`counter.js`), Accessible Mosaic Lightbox (`lightbox.js`), Ken Burns + Scroll-Snap + ARIA Testimonial Carousel (`carousel.js`), and Interactive Tiffin Plate Builder + Menu Tabs with Skeleton Loaders + 404 Quick Finder + Countdown (`plate-builder.js`).
- Self-hosted all Google Fonts (`Cormorant Garamond`, `DM Sans`, `Kalam`) and 100% unique real WebP photography locally under `/assets/`.
- Added JSON-LD `Restaurant` structured data, Open Graph metadata, `sitemap.xml`, and `robots.txt`.
